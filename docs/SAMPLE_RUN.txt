=== CanaryGuard: stopping ransomware inside the Linux kernel ===
  Ransomware scrambles every file it can reach and then demands money.
  CanaryGuard is a driver INSIDE the kernel. Every program must ask the kernel
  before it opens, changes or deletes a file, so the driver sees every attempt.
  
  Three layers of defence:
    1. canary files    bait documents that no real user ever changes
    2. speed check     no human changes 10 different files in 2 seconds
    3. honeytoken      a fake password file; anyone who reads it is snooping
  
  The attacker today is 'ransim': a HARMLESS imitation of ransomware that only
  works inside the demo folders in /var/tmp/canaryguard-demo.
